# IntentIQ High-Level Overview

IntentIQ is an open-source AI-powered multi-intent discovery engine for e-commerce applications.

## High-Level Capabilities

- **Real-Time Intent Tracking:** Infers multi-intent goals dynamically during active shopping sessions.
- **Dense Vector Search:** Powered by FAISS HNSW index and 384-dimensional dense text embeddings.
- **Explainable Recommendations (XAI):** Provides transparent rationale generation for recommended products.
- **Complementary Bundling:** Recommends "Complete the Basket" product bundles based on co-occurrence graph analysis.
- **Privacy Compliance:** Built-in mechanisms for user data purging in compliance with data protection standards.
